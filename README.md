# DeepSeek 余额桌面挂件

Windows 桌面角落常驻的小挂件，实时显示 DeepSeek 账户余额与当前峰谷价格。
纯 Python 标准库 + tkinter 实现，不需要安装任何第三方依赖。

## 功能

- **余额**：总余额大字显示，并拆分「充值余额 / 赠送余额」；低于阈值自动变色提醒。
- **账户状态**：可用性圆点 + 最近更新时间；断网时保留上一次数据并标注离线。
- **峰谷价格**：当前处于峰时还是谷时、折扣力度、距离下一次切换的倒计时。
- **24 小时时间轴**：把当天的峰时段画在时间轴上，游标随当前时间移动。
- **价格对照表**：`deepseek-flash` 与 `deepseek-v4-pro` 的每百万 tokens 单价，
  每格「左=谷时 / 右=峰时」，当前生效的那一侧会高亮。
- **价格可刷新**：设置里可以「立即刷新」或按间隔自动刷新峰谷价格（默认每天一次），
  直接读官方价格页，官方调价后不用改代码。
- **账本**：标题栏单独一个 `☰` 按钮打开账本窗口，按余额差值自动记录消耗，
  把同一次对话里的连续扣费合并成一条，支持手动记账 / 结算 / 导出 CSV / 清空。
- **主题色**：6 套预设配色 + 自定义主色，改完立刻生效。
- **两种收起形态**：
  - 双击余额数字 → 把「峰谷价格」整块折起来，只留一行
    「谷时 5 折 · 距峰时 09:05:57」的摘要；
  - 把窗口拖到屏幕左/右边缘 → 自动收起成贴边小条：余额横排显示、字号自动缩小，
    **谷时绿底、峰时橙底**，一眼看出现在贵不贵。鼠标停在上面 1 秒自动展开，
    鼠标移开自动收回；按住小条可以沿屏幕边上下滑动，**把它拖离边缘就立刻展开**
    成普通浮窗（拖到哪就停在哪）；右键菜单里也有「取消靠边收起」。
  两种状态都会记住，重启后保持。
- **收起时刷新更勤**：处于收起形态（贴边小条或折叠了峰谷区）时，余额每 30 秒
  刷一次；完全展开后回到设置里的间隔（默认 10 分钟）。
- **交互**：拖动窗口移动（靠近屏幕边缘会自动吸附），**单击余额数字立即刷新**
  （标题栏已经没有单独的刷新按钮了），`⚙` 设置，`☰` 账本，`✕` 退出；
  双击余额数字折叠峰谷区，双击其它位置刷新；
  右键菜单可切换置顶 / 开机自启 / 收起峰谷价格 / 靠边收起 / 回到右下角。

### 收起形态是怎么实现的

挂件是一个固定尺寸的画布，所以「收起」不是隐藏控件，而是**换一套设计尺寸重画**：

- 展开 320×340、折叠峰谷区 320×150、靠边小条 69×46（长宽比 1.5:1，96 DPI 设计值，
  再按屏幕 DPI 缩放）。
- 折叠时按**顶边不动**重算 y 坐标：峰谷价格是"向上收起"的，余额数字不会跳位置；
  展开后如果会超出屏幕下沿，会自动上移一点保证整块都在屏幕里。
- 靠边收起的触发条件：拖动松手时窗口被吸附到工作区左/右边缘，就自动进入小条形态；
  横向贴边，纵向沿用原来的中心位置，之后再拖动只能沿边滑动。
- 悬停展开用 150ms 一次的轻量轮询（读 `winfo_pointerxy`）：指针停在小条上满 1 秒就展开成
  完整面板（仍贴同一侧、纵向对齐），指针移开 0.35 秒后自动收回。拖动中和弹出右键菜单时
  会暂停这个判断，免得误触。
- 刚收起时有个"先离开再回来"的门槛：收起那一刻如果指针还停在小条上（比如抓着窗口右半边
  拖到边缘），不会马上弹开，必须先把鼠标挪开一次，之后悬停才开始计时。
- 把小条拖离边缘超过 24px 就"撕下来"：立刻恢复成完整浮窗，并让窗口跟着光标走。
- 收起状态（小条 / 折叠峰谷区）下 `main.py` 把下次刷新时间往前提，最多 30 秒一次；
  一展开就回到设置里的分钟数。
- 小条底色来自 `themes.py` 的 `dock_idle / dock_peak / dock_error`：谷时绿、峰时橙、拉取失败红。
- 卡片是用 Canvas 画的，圆角矩形以前由"两个矩形 + 四个扇形"拼成，图元之间会留下
  1px 的缝——挂件用颜色键透明，缝里会露出桌面，看起来就是边缘有一圈细白线。
  现在整块圆角矩形由**单个多边形**（每角 8 个点逼近圆弧）绘制，没有任何接缝。
- 窗口位置单独缓存一份，不依赖 `winfo_x/y`——Tk 要等 Configure 事件处理完才刷新，
  拖动松手那一瞬间读到的是旧值，会导致边缘吸附判断错误。
- 折叠 / 靠边的状态、贴哪一侧、纵向位置都存在配置文件里，重启后自动恢复。

## 账本是怎么记账的

DeepSeek **没有提供按对话（request）的账单接口**，`/user/balance` 只能看到总余额，
所以账本是用余额差值推算的：

1. 每次刷新余额（默认 10 分钟一次）跟上一次数值比较。余额**变少**就是这段时间的消耗，
   **变多**则记为一条充值。
2. 相邻两次扣费间隔小于「会话合并窗口」（设置里可调，默认 15 分钟）时，
   认为还在同一次对话里，金额累加、时长延伸；超过窗口就收尾成一条独立记录。
   所以一条记录 = 一段连续的用量区间，可以近似看成一次对话。
3. 想精确切分对话，在账本窗口点「结算当前会话」即可强制断开；
   也可以点「手动记一笔」补录。
4. 挂件没运行的时段不会丢：启动后第一次拿到余额时，会跟上次记录的余额比一次，
   差额记成一条备注为「挂件未运行期间累计」的记录。
5. 数据存在 `%APPDATA%\DeepSeekBalanceWidget\ledger.json`（纯文本，可自己改），
   导出 CSV 用 UTF-8 BOM，Excel 直接能打开；清空前会自动备份成
   `ledger.backup-时间戳.json`。

已知局限：如果同一个 key 还在别的地方用（网页版、其他工具、其他机器），
那部分消耗也会被算进来；合并窗口设小了会把一次对话拆成多条，设大了会把两次对话并成一条。

## 主题色

设置 → 外观里可以换主题配色，6 套预设：深海蓝（默认）、石墨灰、墨绿、紫罗兰、暖砂、纯黑；
点「自定义主色」可以用 Windows 取色器挑任意颜色，点「恢复默认色」还原。

实现方式：颜色不再是写死的常量。`themes.py` 里每套主题只声明底色、描边、主色和
峰谷时间轴的两种底色，其余颜色（悬停色、徽标底色、分隔线、输入框底色）都由 `mix()`
按比例从底色派生出来，所以加一套新主题只要写 5 个颜色。`ui.py` 的调色板由
`apply_theme()` 写入模块级变量，切换主题时整块卡片重画一次——画布上的颜色是"画"上去的，
不像普通控件那样能靠样式表换色。谷时绿 / 峰时琥珀 / 报错红属于语义色，不随主题变，
免得"绿=谷时"的直觉被破坏。

## 峰谷价格是怎么来的

数据来源：<https://api-docs.deepseek.com/quick_start/pricing>（官方没有价格查询 API，
所以只能读这个文档页）。

- 峰时：UTC 周一至周五 `01:00–04:00`、`06:00–10:00`
  → 即**北京时间周一至周五 09:00–12:00、14:00–18:00**
- 谷时：其余所有时间（含整个周末），单价为峰时的 **5 折**
- 公告：2026-09-14 12:00（北京时间）起，`deepseek-v4-pro` 的请求统一路由到
  V4.1 Flash 并按 Flash 价格计费，挂件到点后会自动按 Flash 单价显示。

### 刷新原理

1. **内置默认值**：`pricing.py` 里的 `DEFAULT_*` 常量是兜底数据，程序任何时候都不会
   因为没有网络而显示不出来。
2. **启动时先读缓存**：`%APPDATA%\DeepSeekBalanceWidget\pricing.json`，有效就
   直接用它（所以断网启动也能显示上次同步的价格）。
3. **抓取**：`price_source.py` 用标准库 `urllib` 请求价格页（带 `Accept-Language:
   en-US`，确保拿到英文版页面）。
4. **解析**：用标准库 `HTMLParser` 把页面里的表格还原成二维单元格数组，然后
   - 从 `MODEL` 那一行取模型名（`<sup>` 角标会被忽略）；
   - 找周期单元格 `OFF-PEAK` / `PEAK`，取右侧的 `$` 单价，
     按 `CACHE HIT` / `CACHE MISS` / `OUTPUT` 归类成三档；
   - 从脚注里正则解析峰时时段、生效星期（`Monday through Friday` 会展开成
     周一~周五）、以及「某模型从某时刻起改按另一模型计价」的公告。
   折扣比例不是写死的 0.5，而是用**解析到的实际单价**算出来（基准取中位数），
   官方如果哪天改成 6 折，界面会跟着变。
5. **校验后再生效**：三档单价必须齐全、模型数必须与表头一致，否则视为解析失败。
6. **生效**：成功后调用 `pricing.activate()` 换掉内存里当前生效的 `PriceTable`，
   同时写回 `pricing.json` 缓存、记录刷新时间。界面每一帧都是从这张表读数据的，
   所以模型改名、改价都不需要重启，下一帧就是新值。
7. **失败降级**：抓取或解析失败时**保留原价格表**，挂件底部提示
   「峰谷价格未更新：原因」，1 小时后再试，不会因为网络抖动把价格清空。

设置里的开关表示：`自动刷新，每 N 小时` 会记录上次成功时间，到点后由挂件的
1 秒时钟触发后台线程去抓；关掉后仍可随时点「立即刷新」。

## 使用

```bat
run.bat                          :: 静默启动（推荐，双击即可）
python main.py                   :: 带控制台启动，便于看报错
python main.py --set-key sk-xxx  :: 写入 API key 并启动
python main.py --interval 15     :: 刷新间隔改为 15 分钟
python main.py --threshold 10    :: 余额低于 10 元时变色提醒
python main.py --reset-position  :: 回到右下角默认位置
python main.py --refresh-pricing :: 抓取官方价格页并更新峰谷价格缓存
python main.py --no-auto-pricing :: 关闭峰谷价格自动刷新
python main.py --print-config    :: 显示配置文件路径
```

首次使用请点 `⚙` 打开设置，填入 API key（也可以直接用 `--set-key`）。

## 打包成 exe

双击 `build.bat`，产物为 `dist\DeepSeekBalanceWidget.exe`，可直接发给别人用
（前提是没装 Python 也行，PyInstaller 会带上运行时）。打包前记得先执行
`python main.py --set-key sk-xxx` 之外的步骤都不需要——key 存在用户自己的
`%APPDATA%` 里，不会被打进 exe。

打包后在右键菜单勾选「开机自启」，会写入
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`。

## 安装包

双击 `build_installer.bat` 会打出 `dist\DeepSeekWidget-Setup.exe`（安装包）。它做的事：

- 安装到 `%LOCALAPPDATA%\Programs\DeepSeekBalanceWidget`，**只装当前用户，不需要管理员权限**，
  不写 HKLM；安装位置可以在界面上改。
- 创建开始菜单快捷方式，可选桌面快捷方式、开机自启、装完立即运行。
- 注册到「设置 → 应用 → 已安装的应用」，卸载时清理快捷方式、自启项和注册表项。
- 卸载默认**保留**配置、API key 和账本（`%APPDATA%\DeepSeekBalanceWidget`），
  想一并删掉可以在卸载界面勾选。
- 安装前会自动结束正在运行的挂件（否则 exe 被占用覆盖不了）。

静默安装（适合脚本或重装）：

```bat
DeepSeekWidget-Setup.exe --silent --dir D:\Tools\DeepSeekWidget
DeepSeekWidget-Setup.exe --silent --no-desktop-shortcut --no-autostart
DeepSeekWidget-Setup.exe --update --silent      :: 覆盖更新到已安装的位置
"%LOCALAPPDATA%\Programs\DeepSeekBalanceWidget\Uninstall.exe" --uninstall --silent
```

窗口模式下没有控制台，静默模式的日志写在 `%TEMP%\deepseek-setup.log`。

### 覆盖更新

安装程序会自动找出已有的挂件，不需要先卸载：

1. 优先读注册表里上次安装的位置和版本；
2. 没有注册表记录时，**直接看正在运行的挂件进程在哪个目录**（绿色版/手动拷贝的也能认出来）；
3. 都没有才用默认目录。

检测到之后，界面上会显示「检测到已安装 v1.4.0：D:\Program — 将覆盖更新，配置、API key
与账本都会保留」，安装按钮变成**覆盖更新**，安装位置自动填好。

更新过程会自动结束正在运行的挂件，替换程序文件，刷新快捷方式与注册表，然后**自动把它
重新启动**（你原来怎么用，更新完还是怎么用）。`%APPDATA%` 里的配置和账本完全不碰。

版本号从 exe 的版本资源里读（`version_app.txt` / `version_setup.txt`），所以哪怕是直接
拷贝的绿色版也能识别出版本。

安装包里的三个文件是这样组装的（`build_installer.bat` 已经全部串好）：
`DeepSeekBalanceWidget.exe`（主程序）+ `Uninstall.exe`（精简卸载器，不含主程序本体）
→ 一起塞进 `DeepSeekWidget-Setup.exe`，安装时释放到目标目录。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `main.py` | 入口：刷新调度、右键菜单、设置面板、命令行参数 |
| `ui.py` | 界面：无边框圆角卡片、时间轴、价格表（按屏幕 DPI 自动缩放） |
| `pricing.py` | 价格表数据结构、峰谷判定、本地缓存读写 |
| `price_source.py` | 抓取并解析官方价格页（纯标准库） |
| `themes.py` | 主题配色与派生色计算 |
| `ledger.py` | 账本数据：会话合并、统计、CSV 导出、持久化 |
| `ledger_window.py` | 账本窗口（统计卡片 + 明细表） |
| `installer.py` | 安装/卸载程序（同时是安装包与卸载器的源码） |
| `deepseek_api.py` | 余额接口调用与错误信息转换 |
| `app_config.py` | 配置读写、DPAPI 加密存 key、开机自启、屏幕工作区 |

## 数据与隐私

- API key 用 Windows DPAPI 加密后存在
  `%APPDATA%\DeepSeekBalanceWidget\config.json`，只能由当前 Windows 用户解密，
  复制到别的机器或别的用户下都解不开，源码里也不会有明文。
- 余额接口是只读的 `GET /user/balance`，不消耗 token。
- 运行日志（仅异常时写入）：`%APPDATA%\DeepSeekBalanceWidget\widget.log`。

## 常见问题

- **数字停在旧值不动**：看 `widget.log`，通常是网络或 key 失效；界面会显示具体原因。
- **窗口找不到了**：`python main.py --reset-position` 回到右下角。
- **不想让它开机启动**：右键菜单取消勾选「开机自启」，或删除注册表
  `HKCU\...\Run` 下的 `DeepSeekBalanceWidget`。
